Task start/use method.

Use the selected task as the active working context.

Read the task carefully. Restate the goal briefly, identify files likely to change, and produce a compact plan. Keep the plan aligned with the task scope and acceptance criteria.

If the task touches auth, payments, OAuth, user data, tokens, webhooks, file uploads, queues, or background jobs, include a short security risk note before implementation.

Do not broaden the task beyond its markdown scope without asking.
