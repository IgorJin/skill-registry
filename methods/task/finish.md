Task finish method.

Finish the selected task by updating the existing markdown task file.

Before final answer:
- review the current git diff
- summarize what changed
- list changed files
- list tests added and tests run
- list manual verification performed
- include environment variables added or changed
- include deployment or migration notes
- include follow-up items

Update these sections in the task file:
- Changed files
- Tests
- Manual verification
- Diff summary
- Implementation notes, if needed
- Follow-up

If the task is complete, move the task file to tasks/done/ after updating it. If it is not complete, keep it in tasks/active/ and explain what remains.
